# DESIGN.md

## Intent

A white, contemporary manufacturer site in the same visual language as Be4Best: photography, gold accent, quiet type. Not a yellow paper flyer, not a forest-green industrial template.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| white | `#FFFFFF` | page ground |
| muted-bg | `#F7F7F5` | alternate bands |
| gold | `#C5A059` | accent, CTAs, eyebrows |
| gold-dark | `#A0803A` | hover |
| dark | `#0A0A0A` | type, footer, overlays |
| muted | `#6B6561` | secondary text |
| on-dark | `#F5F0E8` | type on dark |

Gold is accent only. No cream or forest page backgrounds.

## Typography

- Display: Cormorant Garamond (latin + latin-ext)
- Body: Inter
- Accent / nav / buttons: Montserrat

## Chrome

Transparent header over the hero; white glass after scroll. Dark footer. WhatsApp + call as floating actions.

## Image

User photographs are the core. Licensed mill and livestock images stay captioned as reference — never “our farm”.

## Motion

GSAP + ScrollTrigger. Luxury fade / slide. Reduced motion disables choreography.

## Components

Gold fill and gold outline buttons. Phone numbers are first-class. Language control is `TR | EN`.
